# 原始课程笔记

> 这里存放未经加工的原始课程笔记，按主题分类。

## 命名规范

```
YYYY-MM-DD_课程名称_讲师.md
```

示例：
- `2026-09-01_市场认知与特种作战_讲师A.md`
- `2026-09-15_寡头经济_张劲帆.md`

## 目录结构

```
notes-raw/

├── 02-design-thinking/       # 设计思维与实践
├── 03-business-startup/      # 商业与创业

├── 09-crowdfunding/           # 众筹出海
└── 10-user-field/             # 用户实拍
```

## 沉淀流程

1. 原始笔记放入对应主题目录
2. 使用 `templates/COURSE_NOTE_TEMPLATE.md` 模板整理
3. 提炼核心概念到对应主题的 `knowledge-cards/`
4. 识别可复用框架，升级为 Skill
