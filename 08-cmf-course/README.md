## 本主题概述

CMF（Color, Material, Finish）即颜色、材料、工艺，是硬件产品和消费品设计的关键环节。

这个主题覆盖：
- 颜色理论与应用
- 材料选择与特性
- 表面处理工艺
- CMF 设计流程
- 材料与成本平衡
- 可持续材料
