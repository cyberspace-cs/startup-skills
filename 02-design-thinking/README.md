# 02 设计思维与实践

> ★★★★★ | 113 条课程内容 | 支撑双钻、识别假设、原型、用户反馈和迭代

## 本主题概述

设计思维是**从问题到解决方案的结构化创新方法**，核心是"以人为本"和"快速迭代"。

这个主题覆盖：
- 双钻模型（发现→定义→开发→交付）
- 假设识别与验证
- 原型设计（低保真→高保真）
- 用户反馈收集与整合
- 迭代优化方法
- 设计原则与规范
