# 04 工程技术

> ★★★★★ | 114 条课程内容 | 判断技术可行性、产品开发、系统工程、供应链

## 本主题概述

工程技术是**把产品概念变成可制造、可交付的实物/系统**的核心能力，尤其对硬件和系统类创业至关重要。

这个主题覆盖：
- 技术可行性评估
- 产品开发流程（从概念到量产）
- 系统工程方法
- 供应链管理与评估
- 制造工艺与量产准备
- 技术选型与架构决策
- 质量与可靠性
