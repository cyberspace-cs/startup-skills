# 03 商业与创业

> ★★★★★ | 59 条课程内容 | 支撑商业模式、创业闭环、市场与团队判断

## 本主题概述

商业与创业是**从产品到可持续生意的核心能力**，涵盖商业模式设计、市场策略、团队管理和创业全流程。

这个主题覆盖：
- 商业模式设计与验证
- 市场分析与竞争策略（含寡头经济、博弈论）
- 创业"特种作战"方法论
- 反共识机会识别
- 团队组建与管理
- 融资与资本运作
- 单位经济模型与财务规划
