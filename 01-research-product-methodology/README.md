# 01 调研与产品方法论

> ★★★★★ | 23 条课程内容 | 直接支撑问题定义、用户调研、验证设计

## 本主题概述

调研与产品方法论是创业的起点——**没有正确的问题定义，所有的产品努力都是在错误的方向上加速**。

这个主题覆盖：
- 问题定义与需求挖掘
- 用户调研方法（访谈、观察、问卷）
- 需求验证与假设测试
- 产品机会评估
- 优先级排序方法
